# Assessment Guidelines

These guidelines apply to every summative assessment in the course. They follow Universal Design for Learning (UDL), especially **multiple means of expression**.

## 1. Give learners a choice in how they show understanding

Summative assessments measure whether learners met the learning objectives. The objectives stay the same, but learners choose **how** to show they met them.

- [ ] Offer at least **two or three formats** (e.g., written, spoken or recorded, visual).
- [ ] Every format is graded with the **same rubric criteria**, so no format is easier or harder to earn full credit on.
- [ ] Describe each format clearly enough that learners can choose the one that fits them best.
- [ ] Say how learners can propose a different format and get it approved.

## 2. Provide detailed instructions

- [ ] State the **purpose** of the assessment: which objectives it measures and why.
- [ ] List the **steps** in order, as a numbered list.
- [ ] Give the **requirements** for each format (length, time limit, number of sources, file type).
- [ ] Say **how and where to submit**, and the due date.
- [ ] Link to any resources, templates, or examples, using descriptive link text.
- [ ] Say where learners can get help.

## 3. Align each assessment with the objectives and the lesson content

- [ ] Every rubric criterion maps to **a specific learning objective**.
- [ ] Every learning objective is measured by **at least one criterion**.
- [ ] The assessment only asks for skills and knowledge that were **taught and practiced in the lesson**.
- [ ] Include an alignment table (objective → lesson content → assessment task → rubric criterion) so the alignment is visible to learners and reviewers.

## 4. Make expectations and grading clear

- [ ] Share **how the work will be graded** before learners start: a rubric, a grading checklist, or both.
- [ ] Provide a **work sample** (a model answer or an annotated example) when possible.
- [ ] Rubric levels describe what the work looks like at each level, not just "good / fair / poor".
- [ ] Give the point value of each criterion and the total.
- [ ] Offer a **self-check checklist** learners can use before they submit.

See [Summative Assessment: Make Your Case](summative-assessment.md) for an example that applies all four guidelines.
