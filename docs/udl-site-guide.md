# UDL Site Guide: Finishing the Google Site

The `site/` folder is a complete draft of the UDL version of the lesson. This guide covers:

- where each assignment requirement is met, and
- the steps that have to be done by you in Google (photos, Drive sharing, making the copy).

## Site map

Recreate each HTML file as a page in Google Sites (copy the text and structure; Google Sites handles the styling).

| Google Sites page | Draft file | What's on it |
|---|---|---|
| Home | `site/index.html` | Hook, audience, objectives, how to use the site, choose-your-path cards |
| Learn | `site/learn.html` | Four skills, each taught three ways (Read it / See and hear it / Try it), tips for each approach |
| Worked Example | `site/example.html` | A full argument built step by step, shown in all three formats, with tips per format |
| Assessment | `site/assessment.html` | Format choice, instructions, alignment table, rubric, self-check |
| About the Author | `site/about.html` | Your photo and bio |
| Credits | `site/credits.html` | Image credits, CC licenses, sources, AI-use statement |
| (sub-page or Drive file) | `site/transcript.html` | Audio transcript, which is also the script to record |
| (Google Doc in Drive) | `site/worksheet.html` | CER graphic organizer worksheet |

The two diagrams in `site/images/` are original work, so you can upload them to the site as-is (use the alt text from `learn.html`).

## Step 1: Make the copy of your site

1. Open your original site in Google Sites.
2. Click **More** (three dots, top right) and choose **Make a copy**.
3. Name it so it starts with **UDL-**, e.g., `UDL-Make Your Case`, and click **OK**.
4. Build the pages from the site map above in the copy.

## Step 2: Find two Creative Commons photos

1. Go to [Openverse](https://openverse.org) or [Wikimedia Commons](https://commons.wikimedia.org).
2. Search for "student debate" (Photo 1) and "student public speaking" (Photo 2).
3. Filter for licenses that allow reuse (CC BY or CC BY-SA are easiest). Avoid **ND** (no derivatives) if you plan to crop.
4. Download the photo and note the **T**itle, **A**uthor, **S**ource link, and **L**icense (TASL).
5. Write the citation under the photo and on the Credits page:

   > "[Title]" by [Author] is licensed under [CC BY 4.0].

   Link the title to the photo's page, the author to their profile, and the license name to the license deed. If you cropped or edited it, add "Cropped from original."
6. Openverse has an **Attribute** button that writes this citation for you. Check that it has all four TASL parts.

## Step 3: Add your other three photos

- **Illustrations** (Worked Example, Assessment): `phone-caddy.png` and `debate-scene.png` in `site/images/`, created with AI and credited on the Credits page.
- **Photo 4** (About the Author): a picture of you. If someone else took it, credit them ("used with permission").
- **Photo 5** (About the Author): your own photo connected to your story.

Write alt text for each one that describes what's in the photo and why it's there. Drafts are in each photo slot. In Google Sites, click the image, then **More (three dots) > Add alt text**.

## Step 4: Create and share the Drive files

Create these files in Google Drive:

- **Audio walkthrough:** record `site/transcript.html` in your own voice, or use an AI text-to-speech tool. Save it as an MP3.
- **Transcript:** a Google Doc with the same text (or keep it as a page on the site).
- **CER worksheet:** a Google Doc copied from `site/worksheet.html`.
- **Rubric:** the rubric from the Assessment page as a Google Doc (optional; it's already on the page).

For **each** file:

1. In Google Drive, right-click the file and choose **Share > Share**.
2. Under **General access**, change "Restricted" to **Anyone with the link**, with role **Viewer**.
3. Click **Copy link**, then **Done**.
4. In Google Sites, insert it with **Insert > Drive**, or add it as a link with descriptive text (e.g., "Download the CER graphic organizer worksheet (Google Doc)").
5. Test the link in a private/incognito browser window, where you're not signed in. If it asks for access, the sharing isn't set correctly.
